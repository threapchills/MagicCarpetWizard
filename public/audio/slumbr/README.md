# Slumbr ambience excerpts

These MP3 files are derived from the Slumbr repository supplied by Mike for use in Magic Carpet Wizard. Original source folder: `slumbr/slumbr-main/sounds/`.

| File | Slumbr label | Game use |
| --- | --- | --- |
| sky2.mp3 | Breeze | altitude and flight air |
| sky4.mp3 | Temple | palace / ancient / night atmosphere |
| sky5.mp3 | Rain | rain weather |
| fire3.mp3 | Ember | city warmth |
| fire7.mp3 | Desert | desert and sand weather |
| earth5.mp3 | Forest | farmland / gardens |
| earth7.mp3 | Cave | canyons / ancient stone |
| sea2.mp3 | Brook | gardens / river |
| sea4.mp3 | Lake | river detail |

Prepared as stereo 32 kHz, 96 kbps MP3, with a maximum excerpt length of 24 seconds and loudness normalization to -24 LUFS / -4 dBTP. Source recordings remain untouched. The game chooses different overlapping portions with slow gain, filter, and stereo changes; these files are not played as one fixed music track. No additional license to the original Slumbr recordings is asserted by this repository.
